# PDPL Compliance Copilot

An AI-powered assistant designed to support Saudi Personal Data Protection Law (PDPL) compliance by analyzing privacy policy text, classifying privacy-related clauses, and retrieving relevant legal provisions.

## Project Overview

PDPL Compliance Copilot is a project developed as part of the AI Engineering Bootcamp. It combines Natural Language Processing (NLP), Machine Learning (ML), and Retrieval-Augmented Generation (RAG) techniques to support the analysis of privacy policies against Saudi PDPL requirements.

The project aims to help users identify relevant privacy policy clauses, retrieve supporting legal references, and facilitate privacy compliance reviews.
